لوحة التحكم لسه غير متصلة

الداشبورد والفورم والصور جاهزين في الكود، بس محتاجين مشروع Supabase عشان يشتغلوا فعليًا. الموقع نفسه شغال عادي دلوقت (الفورم بيروح واتساب، والصور ثابتة) — مش هيتأثر لحد ما توصّل Supabase.

  1. اعمل مشروع مجاني على supabase.com
  2. شغّل ملف supabase/schema.sql من مجلد المشروع في SQL Editor
  3. اعمل Storage bucket اسمه gallery وخليه Public
  4. اعمل مستخدم أدمن واحد من Authentication > Users
  5. هات Project URL و anon key من Settings > API وحطهم في assets/js/supabase-config.js

التفاصيل الكاملة خطوة بخطوة في ملف supabase/التعليمات.md.
